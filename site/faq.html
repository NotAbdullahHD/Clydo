the short answers

faq

is it free?

yes. there is no premium tier and no command asks for money. the coin in the economy is fictional and never leaves the server's own data.

can i invite it right now?

not yet. slink is in private beta while the remaining commands get ported and the rough edges sanded down — which is why there is no invite button anywhere on these pages. the commands list is real in the meantime.

is the source available?

no. slink isn't open source, so there's no repository link to follow. questions about behaviour go to whoever runs it in your server.

what permissions does it need?

send messages, embed links, read history and add reactions for the basics. moderation commands need their own permission — ,ban needs ban members, ,timeout needs moderate members — and are refused with a plain reason when it's missing.

can i change how it looks in my server?

,customize is the one command that changes the bot's face. avatar, banner and bio are set through discord's per-server profile, so they apply to your server alone and every other server keeps the stock look. server owner only, and reset puts it back.

where is the shop?

not built. ,shop and ,buy reply that shop items have not been created yet, rather than pretending there's a catalogue.

why only two slash commands?

because the bot is built around typing. /help and /ping exist so nothing has to be memorised before the first command, and everything else lives on the , prefix.

still curious?

the commands page has every name, alias and one-line description.
