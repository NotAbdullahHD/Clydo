faq

questions, answered plainly.

is it free?

yes. there is no premium tier and no command that asks for money. the economy coin is fictional and stays in the server.

what permissions does it need?

the invite asks for the usual set: send messages, embed links, read history, manage messages, kick and ban, timeout members, manage nicknames and roles. you can strip what you don't use afterwards.

can i change how it looks in my server?

yes — ,customize, server owner only. avatar, banner and bio are set for your server alone, and reset puts them back.

where is the shop?

not built yet. ,shop and ,buy say so honestly instead of pretending.
