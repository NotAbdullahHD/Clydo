one line, when it fits

confirmations and refusals are a single sentence with a green or red edge. nobody needs a field grid to hear that a deposit worked.

lavender is an accent

it shows up in the odd mark, never as the background of every embed. the surface stays #2b2d31 so replies blend into discord.

numbers get shorter

191900 is 191.9K, and 999999 rounds up to 1M instead of printing 1000K.

a panel when the data is real

commands with something to report build one panel: lowercase title, data lines led by a single ›, a footer only when it earns its place. no thumbnails, no emoji soup, no repeating the command name in the body.

and nothing else

no › bullet walls in a two-line reply, no decorative dividers, no all-lavender embeds. if a reply can be one line, it is one line.
